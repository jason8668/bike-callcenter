# 自行车客服系统操作指南（简明版）

这套系统就三部分，先有个整体概念，后面就不迷糊了：

| 部分 | 是什么 | 地址 |
|---|---|---|
| 客服系统（工单台） | 坐席每天用的界面：接单、派单、回访、办结都在这里 | http://36.139.118.227:8899 |
| 模拟来电页 | 还没接电话线路时，用它假装客户打来电话，触发工单 | http://36.139.118.227:8890/test |
| 电话系统（IPPBX） | 以后接 400 电话用的，第二阶段才装，现在没有 | — |

中间还有一个看不见的「中间件」在后台干活：把来电信息、录音自动塞进工单里，不用人工录入。

**一期范围（现在做的）**：这是一套电话客服记录系统——客户打电话进来、客服接听、
全程录音保存、把客户的问题记录成工单，能派单、回访、办结、查询，就这些。
**文字客服（在线文字回复、邮件文字处理）是二期开发内容，一期不启用，也没有要求**，
所以系统里不用配邮箱，看到文字渠道的菜单不用管它。

## 一、人员分工

- **管理员**：建账号、改设置，平时不接单。
- **客服坐席**：接电话、登记问题、派单、回访、办结。
- **运维人员**：收到派单后去现场修车，处理完把结果和照片回传（账号就是客服坐席账号，系统只有管理员和客服坐席两种角色）。

## 二、正常流程（接了电话以后，每天就是这个循环）

1. **客户来电**：客户拨打 400 电话，直接进客服队列，不设按键分类。
2. **坐席弹屏**：上班时坐席先打开来电看板（http://36.139.118.227:8890/board，
   填一次访问密钥后点「开始值班」），电话转到坐席时，看板页会闪红提示并
   自动跳到新工单（不用盯着待办列表的小点，Zammad 自己是不会自动打开工单页的）。
   工单打开后这个标签页就变成工单页了，处理完点收藏夹回到看板，下一通继续自动弹。
   老客户再打来时，新工单正文最上面会自动多一行「历史提示」，
   写清这个客户以前报过什么问题、关键词是什么（比如：还车异常出现过 2 次、
   最近一次是上周的锁桩故障），坐席接起电话就心里有数。
3. **接听自动建单**：接起电话的同时，系统自动生成一张工单，
   来电号码、通话编号都自动填好（录音在挂断后自动附上）。通话中坐席只需补填：
   单车编号、服务类型（还车异常 / 借车异常 / 锁桩故障 / 车辆损坏 / 掉链 /
   乱停放 / 扣费退款）、服务地点、问题描述，有照片可以随单上传。
4. **派单**：需要现场处理的，坐席把工单的「负责人」选具体的运维人员
   （同在客服组），状态保持「处理中」，保存即可，运维人员在自己的界面就能看到这张单。
5. **现场处理回传**：运维人员修完，在工单里写处理结果、上传现场照片，
   状态改成「待回访」。
6. **客服回访**：坐席打电话确认客户满意，在工单里记回访结果。
7. **办结**：状态改成「已办结」，这张单就归档了，全程记录都在，
   随时能按手机号、单车编号、工单号查回来，录音在工单里点开就能听。

**没人接的电话怎么办**：队列里没人接听（或非工作时间），系统会请客户语音留言。
留言会自动变成一张「语音留言」工单（在客服组），录音就在工单附件里。
坐席在界面左侧概览点「语音留言」，就是全部留言的列表（和老系统的语音留言列表一样），
点开听完录音、回拨客户处理，再把工单办结即可。

超时没人处理的单不用担心：工单列表里一直挂着，状态不是「已办结」的都在眼前，
每天上班先看一遍列表就不会漏。

## 三、现在就能用的测试流程（没有电话线路版）

1. 浏览器打开客服系统 http://36.139.118.227:8899 ，用坐席或管理员账号登录，
   **页面开着不要关**。
2. 再打开模拟来电页 http://36.139.118.227:8890/test ：
   - 填一个客户手机号（随便编一个真实格式的，如 13800000000）；
   - 来电不带预分类，不用选问题类型；
   - 第一次用要填访问密钥（在服务器的 middleware/.env 里，问管理员要，
     填一次浏览器就记住了）；
   - 点「发起模拟来电」。
3. 切回客服系统页面：会看到来电提示，接通时工单就已自动生成，
   标题、来电号码都已填好，工单先进客服组（未分类）；挂断后录音自动附上
   （测试录音是 1 秒静音，真录音以后就是通话内容）；坐席在通话过程中就
   可以在工单里补填服务类型、单车编号等分类信息。
4. 接着按正常流程练后半段：补填单车编号等字段 → 改负责人派单 →
   用运维账号登录写处理结果、改「待回访」→ 回坐席账号记回访 → 改「已办结」。
   整个流程就走完了一遍。
5. 测试页下半部分还能「模拟留一条语音留言」：点完到客服系统左侧概览
   「语音留言」里看那张留言工单，附件里的录音能播放，留言这条线也验通了。

## 四、日常操作速查

- **查工单**：界面顶部搜索框，输入手机号、单车编号或工单号，回车。
- **看我的单**：左侧「概览」里有按状态和负责人分的列表，点进去就是。
- **改状态 / 换负责人**：打开工单，在右侧栏改「状态」「负责人」「分组」，点更新。
- **加内部备注**：在工单里写回复时选择「备注」，客户看不到，内部沟通用。
- **听录音**：打开工单，附件区点录音文件即可播放。
- **加新坐席账号**：打开 http://36.139.118.227:8890/agents，只填账号和密码就能新建
  客服坐席账号（建好就能登录）；也可以用 deploy/create_agent_users.rb 批量建号。
- **每日话务量**：浏览器打开 http://36.139.118.227:8890/stats/daily?date=2026-10-24
  （日期换成当天），能看到当天来电总数、接通数、平均通话时长。
- **导出 Excel**：测试页（8890/test）最下方「导出 Excel」区，选天数后点
  「导出工单列表」或「导出通话记录」，直接下载 .xlsx。
  工单表含：工单号、标题、工单类型、服务类型、状态、优先级、分组、
  客户电话、单车编号、服务地点、通话ID、录音地址、投诉等级、创建时间、
  更新时间——和老系统的导出项一一对应。

## 五、常见问题

- **界面还有英文**：先退出账号重新登录一次，再按 Ctrl+F5 强制刷新。
  还剩的个别词截图发管理员处理，系统支持逐条改成中文。
- **模拟来电点了没生成工单**：多半是密钥填错，或后台配置脚本还没跑。
  页面下方会显示原因，把那行字发给管理员看。
- **找不到某张单**：用手机号搜；还不行就看「概览」里的全部工单列表，
  按时间往前翻。
